# Oh, There It Is! 📍

*It's around here somewhere. We'll remember where.*

A friendly little web app that remembers where you put your stuff. Snap a photo, say where it went ("Garage → Red Christmas Bin #3"), and ask for it later — the app tells you exactly where to look.

- **I PUT IT AWAY** — photo, name, place, exact spot, category, ⭐ Important
- **FIND IT FOR ME** — ask in plain words, get the answer with the photo
- **My Things** — everything grouped by location or category
- Private by design: everything is saved on your own device, nothing is sent anywhere
- Backup & restore built in

The whole app is one file: `index.html`. Open it in any browser.
